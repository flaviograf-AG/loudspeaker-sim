# Cross-Validation: Rust Solver vs QSpeakers C++ Formulas

Generated by `solver/reference_solver.py`

## Methodology

QSpeakers (https://github.com/be1/qspeakers) uses a normalized transfer
function approach from `system.cpp`. Our Rust solver uses a full
electromechanical equivalent circuit model. Both implement the same
underlying physics (Small 1972/1973) but via different mathematical paths.

**Comparison method:** Both solvers' output is normalized to their own
1 kHz passband level. The delta shows the difference in *relative shape*
(how much the response deviates from passband at each frequency).

Deltas > 3 dB are flagged as potential bugs (marked with ***).

## QSpeakers Formulas (from system.cpp)

### Sealed Box
```
vr = Vas * N / Vb
qr = sqrt(vr + 1)
qtc = qr * Qts
fb = qr * Fs
fr = (f/fb)^2
dB = 10 * log10(fr^2 / ((fr-1)^2 + fr/qtc^2))
```

### Vented Box
```
A = (Fb/Fs)^2
B = A/Qts + Fb/(Ql*Fs*Qts)
C = 1 + A + Vas*N/Vb + Fb/(Ql*Fs*Qts)
D = 1/Qts + Fb/(Ql*Fs)
fn2 = (f/Fs)^2; fn4 = fn2^2
dB = 10 * log10(fn4^2 / ((fn4 - C*fn2 + A)^2 + fn2*(D*fn2 - B)^2))
```

### Remaining Vented Deltas

The small remaining deltas are explained by two modeling differences:

1. **Voice coil inductance (Le):** Our solver includes Le in the impedance
   model, which slightly changes the effective drive force at all frequencies.
   QSpeakers ignores Le entirely. Drivers with higher Le/Re ratio (like the
   RS180 in Test Case 8) show consistently larger deltas (~2-3 dB).

2. **Rolloff region (< Fb):** Below port tuning, the 24 dB/octave rolloff
   is sensitive to small parameter differences. Our circuit model computes
   Fb from physical port dimensions (with end corrections), while QSpeakers
   uses Fb as a direct parameter. Slight Fb differences are amplified by
   the steep rolloff slope.

### Key Modeling Differences

| Feature | QSpeakers | Our Rust Solver |
|---------|-----------|-----------------|
| Voice coil inductance (Le) | Ignored | Included |
| Radiation impedance | Ignored | ka << 1 piston |
| SPL output | Relative (0 dB passband) | Absolute dB SPL at 1m |
| Box losses (Ql) | In transfer function | Circuit resistance |
| Port end correction | N/A (uses Fb directly) | Flanged/unflanged |
| Math approach | Normalized polynomial | Complex impedance circuit |
